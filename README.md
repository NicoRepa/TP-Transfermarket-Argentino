# TP-Transfermarket-Argentino

## Comandos basicos necesario para manejar el repo con git
 *   git clone https://github.com/NicoRepa/TP-Transfermarket-Argentino.git
 *   git branch (ven las ramas del repo)
 *   git checkout <nombre_rama> (cambian a la rama que quieran ir)
 *   git add . (agregar todo lo nuevo, ya sea modificaciones o nuevos archivos. si solo queres agregar un archivo en vez de poner un punto pones el nombre del archivo a agregar)
 *   git commit -m "mensaje del commit" (siempre necesario antes de subir un cambio al repo)
 *   git push -u origin main (por lo general se usa una sola vez, despues con git push alcanza)
 *   git pull (traes los nuevos cambios de la rama donde estas)
